# 범용 ERP 기능 체크리스트 대비 구현 현황 — 2026-11-10 (2차 구현 반영)

범용 ERP 7개 모듈 체크리스트를 현재 **살롱 데스크(단일 매장 미용실 ERP)** 코드와 대조한 결과입니다. 1차 점검 이후 미구현 항목을 구현해 반영했습니다.

## 이번에 추가한 기능 요약

| 화면 | 위치 | 내용 |
|---|---|---|
| 근태 · 휴가 | 업무 메뉴 (전 직원) | 출근·퇴근 기록, 연차 잔여, 월간 근무 요약, 휴가(연차·반차·병가·경조사·무급) 신청, 연장·야간·휴일 근무 신청, 팀 휴가 일정, 원장·매니저용 오늘 팀 출근 현황 |
| 공지사항 | 업무 메뉴 (전 직원) | 원장·매니저 작성·수정·상단 고정·보관, 직원별 읽음 확인, 읽지 않은 공지 메뉴 배지 |
| 인사 · 근태 | 원장 관리 | 신청 승인·반려·승인 취소, 출퇴근 정정·추가·삭제(사유 필수), 월간 근태 집계, 연차 현황, 조직도, 인사 발령 이력, 재직·경력증명서 발급·재인쇄, 퇴직금 추정 |
| 경비 · 손익 | 원장 관리 | 지출 등록·수정·취소(분류·결제수단·증빙), 법인카드 CSV 가져오기(중복 제외), 월별 간이 손익계산서, 경비 분류별·거래처별 매입, 미지급금 |
| 기존 화면 확장 | — | 직원 인사정보(입사·퇴사·생년월일·팀·직위·주소·연차), 급여명세 근태 불러오기·4대보험 공제 계산, 시술별·상품별 매출, 품목 바코드·규격·바코드 검색, 구매 요청(PR)→발주 반영, 매입 현황, 발주서·영수증 인쇄, 매장 로고·사업자정보·알림 설정·4대보험 요율, 접속 기록(로그인 성공·실패) |

휴가를 승인하면 해당 시간에 예약이 차단되고(서버 검사), 승인 전 기존 예약이 있으면 먼저 조정하도록 안내합니다. 공지 읽음 기록은 업무 데이터 버전과 분리된 테이블(`notice_reads`)에 저장해 공지를 열어도 다른 직원의 저장이 충돌하지 않습니다.

| 품목 기준 정보 | ✅ | 분류·단위·포장 용량·입고 단가·판매가·**바코드·규격**, 바코드 스캔 검색 |
| 시스템 환경 설정 | ✅ | 매장 정보·영업시간·**로고·사업자등록번호·대표자·화면 알림 설정·4대보험 요율** |
| 접속 로그 / 수정 이력 | ✅ | 데이터 변경 이력, **접속 기록(로그인 성공·실패·IP)** |

## 7. 🏭 생산/제조 관리

미용실은 제조업이 아니므로 **시술 = 생산, 재료 = 자재**로 대응합니다. 시술별 재료 사용량(BOM), 예약(작업 지시), 수납 시 재료 차감·실제 사용량 조정(실적)까지 지원합니다. 공정·작업장 라인, MPS, 불량률·QC는 범위 밖(➖)입니다.

## 남은 과제와 추천 기능

- **정액권·회원권·선불 충전**: 국내 미용실 매출 비중이 커 다음 우선순위로 권장
- **포인트·적립과 고객 등급**, **예약 알림(문자·알림톡)**: 외부 발송 API 계약 필요
- **온라인 예약(고객용 페이지)**, **시술 전후 사진 차트**
- 결재선이 있는 지출결의, 소득세 간이세액표, 재무상태표
