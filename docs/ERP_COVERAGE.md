# 범용 ERP 기능 체크리스트 대비 구현 현황 — 2026-11-10

범용 ERP 7개 모듈 체크리스트를 현재 **살롱 데스크(단일 매장 미용실 ERP)** 코드와 대조한 결과입니다. 판정 근거는 `server/`, `src/pages/`, `docs/`의 실제 구현입니다.

| 표시 | 의미 |
|---|---|
| ✅ | 구현됨 |
| 🟡 | 일부 구현 또는 미용실 업무에 맞게 단순화한 형태로 구현 |
| ❌ | 미구현 (미용실에도 의미가 있음) |
| ➖ | 단일 미용실 범위 밖 (제조·다지점·B2B 전용) |

## 요약

| 모듈 | ✅ | 🟡 | ❌ | ➖ | 비고 |
|---|---:|---:|---:|---:|---|
| 1. 시스템/공통 | 4 | 3 | 2 | 0 | 권한·감사 이력·백업은 견고, 공지사항·접속 로그 화면 없음 |
| 2. 인사/급여 | 1 | 3 | 4 | 1 | 급여명세는 구현, 근태·휴가·증명서·퇴직금 없음 |
| 3. 재무/회계 | 1 | 3 | 3 | 1 | 매출 정산·매입 대금은 있음, 전표·재무제표 없음 |
| 4. 영업/수주 | 1 | 3 | 1 | 2 | 예약→수납→환불이 수주·출고에 해당 |
| 5. 구매/자재 | 3 | 2 | 0 | 0 | 발주·입고·반품·대금 구현 완료 |
| 6. 재고/물류 | 3 | 1 | 0 | 1 | 용량 재고·실사·부족 알림 구현 |
| 7. 생산/제조 | 0 | 2 | 0 | 4 | 시술별 재료 사용량이 BOM 역할 |

## 1. ⚙️ 시스템/공통 관리

| 항목 | 판정 | 현재 구현 / 부족한 점 |
|---|---|---|
| 조직도/부서 관리 | 🟡 | 부서 개념 없음. 직원 역할(원장·매니저·접수·디자이너)로 조직 구분 (`server/operations.cjs` `staff.save`) |
| 사용자 계정 생성 및 관리 | ✅ | 직원별 계정 발급, 비활성화, 로그인 차단, 비밀번호 초기화, 첫 로그인 비밀번호 변경, 원장 복구 코드 (`server/app.cjs` `/api/users`, `server/recovery.cjs`) |
| 메뉴별/직급별 접근 권한 (RBAC) | ✅ | 4개 역할별 서버 측 권한 검사, 원장 재인증 영역, 본인 급여 인증, 공용 화면 마스킹 (`server/auth.cjs`, `server/privacy.cjs`). 역할별 권한을 화면에서 편집하는 기능은 없음 (고정 정책) |
| 공통 코드 관리 | 🟡 | 품목 분류(`item_categories`)만 관리. 결제수단·상태·역할 코드는 코드에 고정. 국가·화폐는 KRW 단일 |
| 거래처(고객사/협력사) 관리 | ✅ | 고객(검색·중복 연락처·주의사항·보관/복구), 공급 거래처(`suppliers` 테이블) |
| 품목/상품 기준 정보 | 🟡 | 품목명·분류·단위·포장 용량·입고 단가·판매가·기준 수량. **바코드·규격 필드 없음** |
| 시스템 환경 설정 | 🟡 | 매장명·연락처·주소·영업시간·휴무일·시술 메뉴. **회사 로고 업로드·알림 설정 없음** |
| 접속 로그 / 데이터 수정 이력(Audit) | 🟡 | 데이터 변경 이력은 `audit` 테이블과 설정 화면에서 조회. **로그인 성공·실패 접속 로그 화면 없음** |
| 공지사항 및 사내 게시판 | ❌ | 없음 |

## 2. 👥 인사/급여 관리

| 항목 | 판정 | 현재 구현 / 부족한 점 |
|---|---|---|
| 임직원 프로필·인사기록카드 | 🟡 | 이름·연락처·역할·근무 요일/시간·휴게시간·재직 상태. 입사일·주소·경력 등 인사기록카드 항목 없음 |
| 인사 발령 내역 | 🟡 | 역할 변경은 감사 이력으로만 남음. 발령 이력 화면 없음 |
| 증명서 발급 (재직·경력) | ❌ | 없음. 급여명세 인쇄 기능을 재활용해 구현 가능 |
| 출퇴근 기록 | ❌ | 근무 예정 시간만 있고 실제 출퇴근 기록 없음. 급여의 근로시간은 수기 입력 |
| 휴가 신청·승인 | ❌ | 없음. 예약 가능 시간에도 반영되지 않음 |
| 연장/야간/휴일 근무 신청 | ❌ | 급여명세에 연장시간 수기 입력만 가능 |
| 기본급·수당·공제 항목 설정 | ✅ | 기본급, 항목별 수당·공제, 시술 매출 인센티브 비율, 이전 조건 불러오기 (`server/payroll.cjs`) |
| 월별 급여 대장·명세서 발송 | 🟡 | 월별 초안→확정→지급 기록, 명세서 인쇄/PDF, 직원 본인 조회. 이메일·문자 발송은 없음 |
| 퇴직금 및 4대 보험 정산 | ➖/❌ | 자동 산정하지 않음(공제액 수기 입력). 법정 계산은 오류 위험이 커 외부 급여 서비스 연계 권장 |

## 3. 💰 재무/회계 관리

| 항목 | 판정 | 현재 구현 / 부족한 점 |
|---|---|---|
| 일반·지출결의서 작성/결재 | ❌ | 결재선·지출 기록 없음. 임대료·공과금 등 비용 입력 수단 없음 |
| 매입/매출 전표 | 🟡 | 매출은 수납·환불 내역, 매입은 발주·입고·대금 지급 내역으로 존재. 복식부기 전표는 없음 |
| 거래처별 외상 매출금(미수금) | 🟡 | 대시보드의 "미수납 예약"만 존재. 미용실은 현장 결제가 기본이라 외상 매출 관리 필요성 낮음 |
| 거래처별 외상 매입금 및 지급 | ✅ | 발주별 정산 금액·분할 지급·환급·남은 지급액 (`purchase.settlement`). 거래처별 합계 화면은 없음 |
| 전자세금계산서·홈택스 연동 | ➖ | 외부 인증·사업자 공인 연동 필요. 범위 밖 |
| 법인카드 사용 내역 연동 | ❌ | 없음 (카드사 연동 불가, CSV 업로드 형태로만 현실적) |
| 일계표·월계표 | 🟡 | 매출 정산의 일별 수납·환불·결제수단 합계, CSV 내보내기 (`getReport`) |
| 재무상태표·손익계산서 | ❌ | 없음. 비용 기록이 생기면 **간이 손익(매출 − 매입 − 급여 − 경비)** 정도가 현실적 |

| 고객사 주문 B2B 승인 | ➖ | 해당 없음 |

## 5. 🛒 구매/자재 관리

| 항목 | 판정 | 현재 구현 / 부족한 점 |
|---|---|---|
| 사내 구매 요청(PR) 취합 | 🟡 | 부족 재고에서 체크식 간편 발주로 바로 연결. 직원이 요청하고 원장이 승인하는 별도 PR 단계는 없음 |
| 발주서(PO) 발행 | ✅ | 거래처·품목·포장 수량·단가 스냅샷 보존 (`server/procurement.cjs`). 발주서 인쇄 양식은 없음 |
| 납품 검수 및 입고 | ✅ | 부분 입고, 전량 수령 시 자동 완료, 미입고 잔량 취소 |
| 불량품 반품(반송) | ✅ | 거래처 반품 수량 기록, 재고·정산액 감소 |
| 기간별/품목별/거래처별 매입 분석 | 🟡 | 발주 목록 필터·지급 상태 조회. 집계 리포트 화면 없음 |

| 입고·출고·반품에 따른 재고 증감 | ✅ | 입고·시술 소모·상품 판매·환불 재입고·거래처 반품·실사 조정 이력 |

## 7. 🏭 생산/제조 관리

미용실은 제조업이 아니지만 **시술 = 생산, 재료 = 자재**로 대응시키면 일부가 이미 구현되어 있습니다.

| 항목 | 판정 | 현재 구현 / 부족한 점 |
|---|---|---|
| BOM 관리 | 🟡 | 시술별 재료 사용량(`services.materials`)이 BOM 역할 |
| 공정·작업장 라인 | ➖ | 해당 없음 (디자이너 = 작업자) |
| 수주 기반 생산 계획 (MPS) | ➖ | 예약 일정이 이에 해당하나 계획 산정 기능은 불필요 |
| 작업 지시서·자재 투입 지시 | 🟡 | 예약·시술 시작과 수납 시 재료 차감, 실제 사용량 조정 |
| 생산 완료 실적 등록 | ➖ | 수납 완료가 실적에 해당 |
| 불량률·QC | ➖ | 해당 없음 (재시술·클레임 기록이 대응 개념) |

## 우선 추가 후보 (미용실 업무 효과 순)

1. **근태·휴가** — 출퇴근 기록, 휴가 신청·승인, 휴가일 예약 차단, 급여명세 근로시간 자동 채움
2. **공지사항 게시판** — 원장 작성, 직원 확인 여부
3. **비용(지출) 기록과 간이 손익** — 경비 입력 → 월별 매출 − 매입 − 급여 − 경비
4. **시술·상품별 매출 분석과 거래처별 매입 집계**
5. **증명서 발급** — 재직·경력증명서 인쇄 (인사기록에 입사일 추가 필요)
6. **품목 바코드·규격, 매장 로고, 로그인 접속 로그**

전자세금계산서·홈택스·법인카드 연동, 4대 보험 자동 산정, 다창고 이동, MPS·공정·QC는 단일 미용실 범위를 넘거나 외부 인증·법정 계산이 필요해 제외를 권장합니다.
